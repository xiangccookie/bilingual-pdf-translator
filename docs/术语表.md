# 专业术语表（生物医学）

## 一、它解决什么问题

机器翻译「认得词，但不认行话」。实测这次引擎的原始输出：

| 英文 | 引擎裸译 | 应该译成 |
|---|---|---|
| type strains | 类型菌株 / 种类菌株 | **模式菌株** |
| clades | 花纹 | **进化支** |
| psoriasis | 多病病人 / 病患者 / 磷酸盐 | **银屑病** |
| in silico | 硅酸盐 / 硅胶里 | **计算机模拟** |
| hazard ratio (HR) | 危险比率 / 危险率 | **风险比** |
| GenBank | 基因银行 | **GenBank**（保留原文） |

开术语表后同一批句子变成：`模式菌株` / `进化支` / `银屑病` / `计算机模拟` / `风险比`。

## 二、在界面里怎么改（最快的方式）

程序窗口的「翻译引擎」那一行有三个东西：

| 控件 | 作用 |
|---|---|
| ☑ **使用专业术语表** | 勾上就启用术语校正（默认勾选） |
| **专业词汇表…** | **点一下直接用记事本打开你自己的术语表文件**，改完保存 |
| **重载术语表** | 改完不用重启程序，点它重新读一遍并提示「共几条」 |

点「专业词汇表…」打开的是**你自己的那份**，位置在：

```
%LOCALAPPDATA%\BilingualPdfTranslator\glossary\biology.tsv
```

程序第一次需要时会自动把「出厂词汇表」复制到这里。**为什么不直接改安装目录里的那份**：
安装目录在升级时会被覆盖、而且可能没有写权限；改自己的副本，升级不丢。

## 三、文件格式（记事本直接编辑）

**Tab 分隔的四列**，一行一条：

```
英文 <Tab> 规范中文 <Tab> 备注（可空） <Tab> 已知错误译法（可空，分号分隔）
```

例如：

```
type strains	模式菌株	分类学	类型菌株;种类菌株
psoriasis	银屑病	皮肤病	磷酸盐;多病病人;病患者
in silico	计算机模拟	例：in silico analysis	硅酸盐;在硅化物中
GenBank	GenBank	数据库名，保留原文	基因银行
```

规则：

- **分隔符必须是真正的制表符（Tab）**，不是空格。
  在记事本里直接按 Tab 键即可。**不要用 Excel 另存**（它可能自动改格式）；
  如果非要用 Excel，请存成「文本（制表符分隔）」。
- 以 `#` 开头的是注释行，不生效
- 英文匹配**不区分大小写**，并自动兼容复数（+s / +es）
- 第 4 列可以留空——程序会自动标定（见下节）；这一列用于「我已经知道它错成什么、
  想立刻生效」的情况

## 四、它怎么做到的（决定了你能怎么用）

**没有采用「先把术语换成占位符、译完再换回来」**——实测这个模型会把占位符译烂
（`ZXQ12` → `ZQQ12`），也会把塞进英文句里的中文吃掉（`All 分支 of the tree` →
`树上的所有 XXX`）。那条路不可靠。

实际做法是 **译后校正 + 自动标定**：

1. 术语表给出「英文 → 规范中文」；
2. **首次使用时**让引擎把每条术语**裸译一次**，把它的错误译法记下来
   （约 130 条约 16 秒，结果缓存在数据目录，术语表改了才重算）；
3. 整句译完后，**若英文原句里出现了该术语**，就把译文里那个错误译法换成规范译法。

第 3 步为什么要看英文原句：错误译法可能是别处的正常用词
（`clades` 被译成「花纹」，而「花纹」在别的句子里可能是对的）。
有英文侧触发条件，替换就是定点、安全的。

**一个诚实的限制**：同一个术语，引擎在不同句子里会换说法
（`type strains` 有时译「类型菌株」、有时译「种类菌株」）。
自动标定只能抓到一部分，所以术语表第 4 列手工补的变体最可靠。

为此程序会**主动告警**：某个术语在英文里出现了、但译文里既没有规范译法也没有已知错误译法时，
日志里会出现

```
术语未校正：xxx（译文里没找到规范译法「yyy」，可在术语表第 4 列补一条它的机器译法）
```

跑完之后还会汇总一句「有 N 个术语引擎换了说法」。看到这类提示，把那句话里的错误译法
追加到第 4 列、点「重载术语表」即可。

## 六、边界：它做不到什么

- **只覆盖表里有的术语**。表外的词仍是机翻。
- **术语对 ≠ 译文通顺**。它只替换词、不改语序，机翻腔仍在。
  对外交付仍建议人工过一遍。
- **不猜同义词**。表里写 `type strain`，句子里是 `type strains` 能命中；
  出现 `type culture`、`type material` 要另加一行。

## 七、关掉它

- 界面上取消勾选「使用专业术语表」
- 命令行加 `--no-glossary`

关掉后回到引擎原始输出，方便对比术语表的效果。
