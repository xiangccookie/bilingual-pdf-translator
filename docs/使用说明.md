# 使用说明（给使用者）

## 一、这是什么

把英文学术 PDF 变成「**一句英文，紧跟这句中文**」的双语 PDF。

桌面上的 `BilingualPdfTranslator.exe`（在解压目录里）双击即可用：
**不需要 Python、不需要配置环境变量、不需要联网、不需要 API Key。**

## 二、三步操作

1. **添加文章**：点「添加文件…」（可按住 Ctrl 多选）或「添加文件夹…」（整个文件夹的 PDF 全加进来）。
   列表里会显示「1. 某论文.pdf / 2. …」，右下角显示「共 N 篇」。
2. **选输出文件夹**：点「选择…」。所有成品都写到这里。
3. **开始翻译（全部）**：队列里的文章会按顺序逐篇跑完；某篇出错只跳过那篇。

跑的过程里能看到：第几篇、当前在做什么（提取 → 清理裁图 → 逐句翻译 → 合成）、
进度条，以及最后「成功 N 篇 / 失败 M 篇」的清单。

## 三、文件名怎么来的

下拉框可以选：

| 选项 | 输出文件名示例 |
|---|---|
| **论文标题的中文译名**（默认） | `胃癌巨噬细胞相关基因预后特征.pdf` |
| 论文标题的英文原文 | `Bioinformatics analysis of macrophage-associated genes….pdf` |
| 沿用原文件名 | `paper.pdf` |

> ⚠️ **中文译名是机器翻译的，个别词会错**。实测：`psoriasis`（银屑病）→「磷酸盐」、
> `taurine`（牛磺酸）→「陶林」、`gold standard`（金标准）→「金本位」。
> 重要文章建议选「英文原文」命名，或翻完手动改个准确的中文名。

同名文件不会被覆盖，会自动加 `（2）`、`（3）`。

## 四、两种翻译引擎

| | 本地离线（默认） | 在线免费（MyMemory） |
|---|---|---|
| 联网 | **完全不需要** | 需要 |
| 费用 / 额度 | 0 元、无限制 | 免费，但每天有额度 |
| 速度 | 0.05–0.15 秒/句，9 页约 45 秒 | 约 0.9 秒/句，易被限流 |
| 前置条件 | 首次自动解压随包模型（约 10 秒） | 无 |

界面上的「安装离线模型」按钮：只有在模型丢失、或你拿到的版本没带模型时才需要点
（会联网下载 67.5 MB）。

## 五、质量：请务必知道

同一句真实论文，三种译法对照：

| 英文 | 人工译稿 | 机器翻译 |
|---|---|---|
| type strains | 模式菌株 | 类型菌株 |
| all clades in the Tree of Life | 生命之树的各分支 | **生命之树中的所有阴道** |
| unnamed or ambiguously named specimens | 未命名或命名含糊的标本 | **未命名或未明确命名的光谱** |
| GenBank | GenBank | **基因银行** |

程序内置一道保险：**英文里的数字必须原样出现在译文里**，否则那句保留英文原文。

**结论**：这个工具适合快速通读、筛选、找重点；**不能替代人工译稿**。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 双击后 3–5 秒才出窗口 | 首次启动要加载模型，正常 |
| Windows 提示「未知发布者」 | 未签名的自打包程序，点「更多信息 → 仍要运行」 |
| 提示没有离线模型 | 点「安装离线模型」（联网一次），或改用在线引擎 |
| 有的句子还是英文 | 那句的数字校验没通过，程序故意保留原文 |
| 一片 PDF 都没有生成 | 看日志：程序同目录或 `%LOCALAPPDATA%\BilingualPdfTranslator` 下的 `app.log` |
| 想批量又要用命令行 | 见 README 第七节 |

## 七、模型存在哪

首次运行时，随包的离线模型会解压到：

```
%LOCALAPPDATA%\BilingualPdfTranslator\model\translate-en_zh-1_9
```

如果该位置不可写，程序会自动换到 `%USERPROFILE%`、`%PUBLIC%`、`%ProgramData%`
等**纯英文路径**（中文路径会因为 sentencepiece 的限制而失败）。

用 `BilingualPdfTranslator.exe --where` 可以看到程序实际选了哪个目录、日志在哪。
